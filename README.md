# Cookatime Prep Week 1

A cozy arcade kitchen management game built with Python and Pygame for the prep weeks of Hack Club's Terra program.

## Hour 1 Features
- Smooth movement with boundary limits
- Diagonal speed normalization to keep movement constant
- Dash mechanic with visual indications

## How to Run (demo in future)
1. Install Pygame: 'pip install pygame' on Powershell/Terminal
2. Download files and run after navigation: 'python main.py'
